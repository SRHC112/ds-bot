# 本机环境

- 本机有 SteamTools HTTPS 拦截，Node 默认不信任其根证书，fetch 会报 unable to verify the first certificate；已导出双根证书到 C:\Users\Administrator\Desktop\ds-bot-work\steamtools-ca.pem，用用户环境变量 NODE_EXTRA_CA_CERTS 指向它修复（2026-11-08）。 [source: part 2 #237; added: 2026-11-08]
- DSH 会把子进程的 NODE_OPTIONS 显式置空，设 NODE_OPTIONS 无效；改用户环境变量后需完全退出 DSH 并从开始菜单重新启动（应用内重启继承旧环境），新变量才生效 [source: part 2 #330; added: 2026-11-08]
- DSH 数据位置：DSH_HOME=E:\dsh-data；Bot 记忆在 E:\dsh-data\bot\memory\（bots\<session>\ 主题 .md、team\MEMORY.md 团队记忆）；配置在 ~/dsh-web-profile.yml 和 E:\dsh-data\profiles\desktop\。备份上传到 ds-bot 仓库 dsh-config/，密钥文件（.credentials.yaml/.env/secrets.json）绝不能上传。 [source: part 3 #103; added: 2026-11-08]
- 本地 git 走不通：schannel 后端过不了 SteamTools 拦截证书的 HTTPS，克隆/推送均失败（2026-11-08 实测）；上传备份改用已保存的 GitHub 令牌走 GitHub API 脚本推送。 [source: part 4 #29; added: 2026-11-08]
