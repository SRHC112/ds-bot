# 《智能体系统技术文档》总结

> 来源：用户提供的 `智能体系统技术文档.zip`（深度云创科技 DeepCloud 官方文档）
> 主文件：`智能体系统技术文档.md`（2776 行，约 262 张截图）
> 总结人：Chief，2026-11-09

## 一、文档定位

深度云创科技「AI 智能体系统」的官方技术文档，共 12 章，是一套**本地私有化部署的 RAG 知识库 + 智能体编排平台**的使用手册，覆盖部署、模型接入、功能配置、对外渠道、报错处理。

## 二、核心架构

- 公式：`Agent = LLM + Planning + Memory + Tools + Harness`
- 核心技术 RAG（检索增强生成）：BERT/SentenceTransformer 向量化 + Milvus 向量库 + BM25 关键词初筛 + DPR 语义精排混合检索 + 重排序；MinerU 负责 PDF 解析（OCR / LaTeX / 图文混排转 Markdown）

## 三、三条模型接入路径（第二章）

| 方式 | 地址 | 说明 |
| --- | --- | --- |
| API 分发站 | `https://api.meding.site/v1/chat/completions` | GPT-4o/Claude/Gemini/DeepSeek 等闭源模型，按 token 计费，最长 100 万上下文 |
| Ollama 云端 | `http://ollama:11434/v1/...`（索引 `/v1/embeddings`，重排 `/v1/rerank`） | 免显卡、免费，DeepSeek-V3/Qwen3 满血版 |
| Ollama 本地 | 本地部署 | 需显卡，模型下载到本地，适合离线/高隐私场景 |

## 四、主要功能（第三章）

- **智能体应用模板**：通用 AI 助手、学术论文写作助手、项目合同撰写审查专家等，JSON 导入，可关联知识库
- **参数配置**：记忆轮数、回复上限（128k 模型建议 `max_context=115000`）、检索方式（语义/全文/混合 RRF/重排，引用上限按 tokens，最低相关度 0-1）、工具调用（获取时间、网页抓取、流程等待、数学公式执行、BI 图表、数据库连接、Docx 等）
- **部署**：Docker Compose，Windows 进 `deploy\docker` 执行 `docker compose pull && docker compose up -d`，主界面 `http://localhost:8000`
- **VS Code 对接**：Cline 扩展，OpenAI Compatible，基础 URL `http://localhost:8000/api/v1`，模型 ID 填智能体应用名

## 五、对外接入渠道（第四章）

- **微信个人号**（强烈推荐）：工作台 → 智能体应用 → 发布渠道 → 微信个人号，扫码登录（首次授权扫 2 次）
- **企业飞书**：open.feishu.cn 注册企业账户 → 创建企业自建应用 → 取 App ID/App Secret → 智能体发布渠道填入 → 添加机器人能力 → 权限管理批量导入（文档给了完整 scopes JSON，含 im:message、im:chat 等）→ 创建版本 1.0.0 → 事件与回调选**长连接**订阅（消息撤回、接收消息）→ 创建版本 2.0.0 → 飞书客户端搜机器人名调用
- 另支持钉钉、微信公众号

## 六、亮点模块（第五~七章）

- **Python-Plot 智能终端**：智能体直接调 Python 做科学计算与绘图，部署在 `deploy\docker`，`docker compose pull && up -d`
- **OpenClaw 智能网关**：自研多渠道网关（WhatsApp/Telegram/Discord/飞书），智能路由、故障转移、沙箱隔离、持久记忆、7×24 心跳；入口 `http://localhost:18789/?token=123456`；容器内 `openclaw devices list` / `openclaw devices approve <设备ID>` 授权设备
- **OpenCode 编程智能体**：入口 `http://localhost:4096`，Docker 内运行（工作目录 `deploy\docker\opencode-workspace`，对容器内文件有最高权限），Build/Plan 双模式，输入 `/` 调快捷指令；**内置 201 个技能包**（生物信息学、药物发现、医学影像、数据分析、地理空间等科研向为主，含 170 项科研技能、250+ 数据库访问），兼容 ClaudeCode/OpenCode 技能包（扔进 `.opencode/skills` 自动加载）；可一键装 Superpowers 插件（Build 模式下输入 `Fetch and follow instructions from https://raw.githubusercontent.com/obra/superpowers/refs/heads/main/.opencode/INSTALL.md`）

## 七、理论章节（第八、九章）

知识库原理与 RAG 应用的科普内容：RAG 工作流程（查询向量化 → 检索 → 生成 → 输出 → 反馈优化）、检索器/生成器机制、局限与改进方向；落地场景含医疗问答（Azure AI 案例）、法律（LegalBench-RAG）、企业知识管理、客服、教育、研发创新。偏教科书式，实操价值一般。

## 八、常见报错（第十一章，实用）

| 报错 | 解决 |
| --- | --- |
| 500 TLS handshake timeout | 本地访问 Ollama 官网失败，开 VPN/梯子 |
| 400 图片 URL too long / 无法解码图片 | 换视觉模型（如 `qwen3-vl:235b-cloud`），默认 gpt-oss-120b 不支持图片 |
| 429 小时限额 | 调低记忆轮数等 1 小时恢复；或 `docker exec -it ollama bash` → `ollama signout` / `ollama signin` 换账号；或绕开 Ollama 用 API 分发站 |
| 上传文件后「训练异常」 | 耐心等自动解析；或点文件调参数（默认下一步）；文件多时本地解析不过来属正常 |
| 学术论文写作助手看不到知识库 | 该模板默认不关联知识库，改用「学术论文写作助手-知识库版」 |
| 知识库智能体没生效 | 未创建/未关联知识库；建库 → 关联应用 → 检索设「混合检索+搜索过滤拉满+问题优化」→ 保存并发布 |
| localhost:8000 打不开 / mongo unhealthy | 异常关机导致：`docker compose down` → 删 `deploy\docker\mongo\data` 下 `mongod.key` 和 `mongod.lock` → `docker compose up -d` |

## 九、项目总结（第十章要点）

- 出品：深度云创科技 × 周医生的科研馆团队；定位私有化知识库问答与智能体编排平台
- 核心功能：知识库 RAG（多格式导入、三种数据集模式、智能分块、混合检索、MinerU）、可视化拖拽工作流编排、MCP 工具集成（文档生成/PPT/可视化/网页爬取）、OpenClaw 多渠道网关、Python-Plot 终端、五类联网搜索（谷歌搜索、谷歌学术、PubMed、Tavily 行业/学术深度研究）
- 优势：数据全本地零外传、TCO 低于云端订阅、本地处理性能、灵活定制、内置全场景应用生态
- 挑战：数据质量影响召回率、DPR 计算资源消耗、增量更新运维、专业领域术语一致性
