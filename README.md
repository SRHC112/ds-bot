# ds-bot

基于 DeepSeek Harness 的 Bot 团队工作仓库。

## 团队结构

| Bot | 职责 |
| --- | --- |
| 写手 | 产出博客和各类文档 |
| 程序员 | 编写代码与部署方案 |
| Chief | 统筹分工、派活与进度跟进 |

## 归档规范

每次工作（对应一个任务或群聊讨论）在本仓库单独建一个顶层文件夹，结构如下：

```
工作名称/
├── 写手/
│   └── 工作过程.md        # 写手的工作过程记录
├── 程序员/
│   └── 工作过程.md        # 程序员的工作过程记录
└── （各 Bot 的产出文件）
```

- 每个 Bot 的产出文件放在它自己的子文件夹里，分门别类保存。
- 每个 Bot 都要写一份 `.md`，记录该次工作过程（做了什么、怎么做的、产出清单）。
- 上传时机在开工时确认：每步完成后上传，或整个工作完成后统一上传。

## 目录约定

- 代码与部署方案由「程序员」维护，附带运行与验证方式。
- 博客与文档由「写手」维护，成稿前先确认目标读者、主题和篇幅。
