# github归档规范

- 工作归档规范（用户 2026-11-08 定）：每次工作在 GitHub ds-bot 仓库单独建一个文件夹，文件夹内每个 Bot 各一个子文件夹分类存放各自产出，且每个 Bot 要在自己文件夹里写一份 .md 记录工作过程；开工时先问用户是工作完成后统一上传，还是每步完成后上传。 [source: part 2 #330; added: 2026-11-08]
- 上传时机询问新增第三选项「校园网」：用户用校园网时暂不上传 GitHub，产出先保存在本地工作文件夹；等用户告知已开加速器后，再由 Chief 执行上传到 ds-bot 仓库。 [source: part 3 #86; added: 2026-11-08]
